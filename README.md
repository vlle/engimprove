# engimprove

Машина для английского: ловит мои ошибки там, где я и так пишу (промпты в Claude Code,
тексты, устные ответы), складывает их в одну базу и возвращает дриллами из моих же фраз —
в вебе, в терминале и уведомлением, когда тема созрела.

## Быстрый старт

```fish
eng open              # веб на http://127.0.0.1:7421, сервер поднимется сам
eng status            # какие темы созрели, сколько карточек к повторению
eng doctor            # OpenRouter, claude, whisper, сервер, упавшие проверки
```

В Claude Code: `/eng-drill`, `/eng-drill the`, `/eng-drill review`.
`eng` без аргументов, как и раньше, открывает Claude-сессию этой папки.

## Как это работает

```
промпт по-английски ──► eng hook (async, ~40 мс) ──► state/queue/<ts>.json
                                                     │
                              eng check (отсоединён) ◄┘
                              ├─ OpenRouter sonnet-5.5, а для ~/wwrum — claude -p
                              ├─ eng log → errors.jsonl, texts/, stats.md
                              └─ state/feedback/<session>.json, state/checks.jsonl
конец хода ──► eng hook-stop ──► «✏️ eng (N): …», «🎯 созрели дриллы …», «📈 неделя …»
                              └─ terminal-notifier: раз за цикл темы, клик открывает дрилл
```

- **Темы** (`config/eng.json`): ошибка попадает в тему по категории, а `the` и `a-an` — ещё и по
  тому, добавляет или убирает правка сам артикль. Тема созревает, когда после последнего
  дрилла набралось `threshold` свежих ошибок; дрилл сдвигает курсор, счётчик обнуляется.
- **Карточки**: клоуз из исправленной фразы, если пропуск угадывается — служебные слова
  (a/an/the/—, предлоги, связки) или замена одного слова с вариантами; иначе «исправь фразу».
  Под заданием — исходное предложение целиком из `texts/`, чтобы фрагмент был понятен. Паки из `drills/packs/<topic>.jsonl` пишет LLM по моим
  ошибкам: кнопка в конце дрилла или `eng pack generate -topic T`.
- **Повторение**: Лейтнер, интервалы 10 мин / 1 / 3 / 7 / 21 / 60 дней, промах — в начало.
- **Говорение**: вкладка Speak, запись в браузере → ffmpeg → whisper.cpp
  (`models/ggml-small.en.bin`, ставится `eng whisper-setup`) → разбор LLM → ошибки в базу.
  Разбор игнорирует пунктуацию и орфографию транскрибера.
- **Прогресс**: ошибки на 100 слов проверенных промптов по неделям (`state/checks.jsonl`),
  серия дней, точность дриллов.

## Приватность и цена

- Промпты из `private_roots` (по умолчанию `~/wwrum`, рабочий контекст WB) в OpenRouter не
  уходят — их проверяет `claude -p` в том же контуре, что и сам Claude Code.
- В очередь кладётся только текст без вставок, кода, URL и путей; файл удаляется после
  проверки. В архив попадают только предложения с ошибками, имена и хосты → `<…>`.
- Ключ OpenRouter берёт фетчер из реестра wt (`openrouter-env`), в коде и конфиге его нет.
- Проверка промпта через sonnet-5.5 — около цента; через `claude -p` — заметный расход
  подписки, модель меняется в `claude_model`.

## Файлы

| путь | что |
|---|---|
| `errors/errors.jsonl` | база ошибок, append-only; писать только через `eng log` |
| `errors/taxonomy.md`, `errors/stats.md` | категории; сгенерированная статистика |
| `texts/` | архив текстов, промптов и устных ответов |
| `config/eng.json` | адрес, пороги тем, модели, приватные корни, уведомления |
| `content/lessons.json`, `content/speaking.json` | уроки по темам, вопросы для говорения |
| `drills/packs/` | сгенерированные упражнения |
| `state/` | srs, ответы, сессии, очередь, фидбек хука, логи (`check.log`, `hook.err`, `serve.log`) |
| `speaking/<id>/` | запись, wav, транскрипт, разбор |

## Если что-то не так

- Правки не появляются в конце хода → `state/hook.err`, `state/check.log`, `eng doctor`.
- Проверка упала (сеть, ключ) → промпт лежит в `state/queue/failed`, `eng check -retry`.
- Поменял фронт → `go build -o bin/eng ./cmd/eng && eng restart` (статика вшита в бинарь).
- Тесты: `go test ./...`.
